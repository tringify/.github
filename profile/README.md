# Tringify

**Everything you need to launch, run and scale an online business, from storefront to checkout to selling worldwide, in one platform.**

Tringify puts more into the core: returns, exchanges, markets, taxes, discounts, gift cards, store credit, reviews, product feeds and Live View come built in, so merchants spend less time managing software and more time building their business.
